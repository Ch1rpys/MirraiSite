# Mirrai 官网 · 项目计划书

> 版本 v1.3 · 由 14 轮设计讨论定稿（修订记录见文末）
> 域名：`mirrai.ink`（已购） · 语言：中文为主，完整英文版 · 仓库：独立新建

---

## 1. 项目概述

**一句话定位**：给"有未竟之言的人"的情感叙事主站，同时承担开源门面、下载分发、产品哲学宣言与 SEO 内容阵地。

**产品背景**：Mirrai 是开源情感记忆操作系统（Emotional Memory OS）。上传真实聊天记录 → 多阶段蒸馏 → 重建 TA 的数字分身。核心命题不是"让 AI 更像人"，而是**帮你和一段关系完成它本该有的结局**。最独特的机制是**毕业机制**——成功指标是毕业率而非留存率。

**官网要达成的五项目标**（全部成立，权重不同）：

| # | 目标 | 权重 | 承载 |
|---|---|---|---|
| 1 | 打动潜在用户并转化 | ★★★★★ | 首页情感叙事 + 下载 CTA |
| 2 | 开源项目门面 / 引流 GitHub | ★★★ | 信任区、页脚、"像不像"屏 |
| 3 | 下载与安装分发 | ★★★★ | `/download` 独立页 |
| 4 | 讲清楚产品哲学 | ★★★★ | 首页毕业机制屏 + `/ethics` + `/about` |
| 5 | SEO / 长期内容运营 | ★★★ | `/blog` 版本博客 + 文档站 |

**与产品的关系**：官网是**独立站点**（独立仓库、独立域名、独立部署）。产品仓库内 `client/src/pages/Landing.tsx` **只加官网链接**，不做内容改动。

## 2. 受众与优先级

| 优先级 | 受众 | 他们要什么 | 官网如何回应 |
|---|---|---|---|
| 1 | **普通用户：有未竟之言的人**（25-35 岁、经历过重要关系） | "这是什么、像不像、敢不敢用、隐私是否安全" | 情感叙事认出自己 → 能力证据 → 信任 → 下载 |

## 3. 站点信息架构

**形态**：首页长滚动（主叙事）+ 少量子页。URL 中文为主 `/`，英文镜像 `/en/`。

```
/              首页 · 九屏长滚动叙事
/download      下载与安装（macOS / Windows / Docker / 源码）
/ethics        伦理与边界
/privacy       隐私说明（无统计脚本 / 日志计数 / 拨测）
/about         品牌故事 + 创作手记全文 + 团队
/blog          版本博客（可读化 changelog）
/blog/[slug]
/docs/*        文档站
  /docs/install/*     安装（Docker / 源码 / macOS / Windows）
  /docs/usage/*       使用（上传→蒸馏→对话→毕业）
  /docs/channels/*    渠道（微信 ClawBot / 飞书）
  /docs/llm/*         LLM 提供商配置
  /docs/faq           常见问题
  /docs/dev/*         开发者（架构 / API / 贡献）
/en/...        以上全部的英文镜像
```

**内容归属边界**：
- 用户文档（安装/使用/渠道/FAQ）→ 官网文档站，**任务导向重写**（"我想在 Windows 上装好"），不是 README 搬运
- 开发者文档（指南/API/贡献）→ 官网文档站，入口级内容
- roadmap v2–v5、eval 协议、open-items 等验收细节 → **留 GitHub**，官网只链接

## 4. 首页九屏叙事规格

叙事原则：**情感先行（最高优先级），但尽早给理性证据**（第 3 屏就进能力），不让理性型访客晾着。

| 屏 | 功能 | 文案方向（示例，非终稿） | 视觉 |
|---|---|---|---|
| 1 **Hero** | 认出产品 | 主：**不在身边的时候，TA 还在这里。**<br>副：上传你们的聊天记录，重建 TA 的数字分身。用 TA 的语气说话，然后——好好告别。<br>CTA：`下载 Mirrai` / `看它怎么工作`<br>角标：开源 · 数据不出本地 · MIT | 纯抽象：暗色纸纹 + 一点暖光 + 消息痕迹。**无人像** |
| 2 **未竟之言** | 让人认出自己，零功能 | 场景叙事：深夜想起没说完的话。引用创作手记："你能对着一个程序问出这句话，却没办法对着一个真实的、爱我的人问出口。"（M1 期引文不带链接，M2 起链 `/about`） | 留白 + 时间痕迹（日期、天数） |
| 3 **怎么做到** | 尽早给理性证据 | 三步：上传聊天记录 → 多阶段蒸馏（7 层人设）→ 用 TA 的语气对话。硬话：不是"模仿 TA"，是把"像 TA"变成"是 TA"。 | 三步式图形 + 产品截图 |
| 4 **TA 不在的时候** | 差异化第三态 | 信（写下来 / 交出去，一天后回信）· 暂时联系不上（沉默有解释）· 先缓一缓（停打扰，不停关系）· TA 那边现在几点 | 对话的形态 + 时间的痕迹 |
| 5 **毕业机制** | 全站高潮 | 大字：**它不是让你留下，是帮你好好告别。**<br>宣言：产品的成功指标不是留存率，是毕业率。<br>**预录对话回放**：对话 → 记忆召回可见 → 告别信 | 消息消隐动效（M4） |
| 6 **像不像** | 给怀疑者与开发者 | 判别规则（"随便" / "随便你"）+ 保真之尺（三字重合率/似然差/长度差/情绪一致），本地跑、可审计 | 规则结构图 `触发词 → 含义 → 表现` |
| 7 **信任** | 隐私与伦理 | 数据本地 · Ollama 完全离线 · MIT · [伦理与边界 →]（**M1 期隐藏此入口**）；CTA 旁一句极小的边界句 | 极简、克制 |
| 8 **下载** | 分发 | macOS / Windows / Docker / 源码，一行系统需求（**M1 期按钮指 GitHub Releases**） | 三平台入口 |
| 9 **尾声** | 回到哲学 | GitHub / 创作手记 / 博客（**M1 期只留 GitHub**）。尾句：**有一天你不再需要它——那就是它做完了。** | 大留白收束 |

**CTA 链接与计数口径**：Hero 主 CTA → `/download`（**M1 期临时直指 GitHub Releases**，M2 起换回）；「看它怎么工作」→ S3 锚点；真实下载计数**只统计 `/download` 页安装包与 Docker 的 `/go/*` 按钮**（Docker 按钮为 `/go/docker` → Docker Hub 镜像页；源码等其余链接直链不计；`/en/` 合并计数）。**M1 零死链策略（含屏内链接）**：导航只含页内锚点 + GitHub 外链；S7「伦理与边界」入口 M1 期隐藏；S8 下载按钮 M1 期指 GitHub Releases；S9 只留 GitHub（创作手记/博客链接 M2/M3 起补）——M2.6 统一切换回正式链接（共五处：Hero CTA、S2 引文、S7、S8、S9）。

## 5. 品牌系统

### 5.1 命名与词源

「Mirrai」为自造词，词源线索：**mirari（拉丁语：注视、凝望）→ 古法语 mirer（注视）→ 英语 mirror（镜子）/ mirage（海市蜃楼）**——映照、镜像记忆里的那个 TA。此词源进 `/about` 品牌故事，也是英文副标题的灵感来源。

### 5.2 标语体系

| 用途 | 中文 | English |
|---|---|---|
| Hero 主标语 | 不在身边的时候，TA 还在这里。 | When they're not here, they're still here. |
| 品牌页定位语（词源线 C） | 从 mirari——凝望。 | From *mirari* — to gaze. A mirror for the conversations you can't have anymore. |
| 毕业哲学句（D，辅） | 它不是让你留下，是帮你好好告别。 | Designed to let you go. An AI companion whose success metric is your graduation. |
| 信任语 | 开源 · 数据不出本地 · MIT | Open source · Your data never leaves your machine · MIT |

### 5.3 Logo（定稿：V3「空与在」）

- **形态**：两枚气泡隔镜面轴对望。**左气泡空心（不在身边）＝ ink 色描边；右气泡实心暖光（TA 还在这里）＝ lamp 色填充**，内有一点反色的"灯"。
- **字标**：`Mirrai`，Cormorant Garamond，字距 `.22em`。
- **Lockup 规范**：
  - 横排（符号 + 字标）：桌面导航 / Hero
  - 竖排（符号在上、字标在下）：移动端 / 分享卡
  - 纯符号（圆角方容器内）：favicon / app icon
  - 纯字标：页脚 / 版权行
- **Favicon**：16/32/48px 均可辨（左空心描边——暗主题白描边 / 亮主题深描边；右暖实心，双色团块）
- **OG 卡**（1200×630）：符号 + 字标 + 主标语 + 信任语一行

### 5.4 字体系统

| 角色 | 字体 | 用法 |
|---|---|---|
| 字标 | **Cormorant Garamond**（字距 .22em） | logo、页脚字标 |
| 大标题 | **Playfair Display** | H1 / H2，页面大标题 |
| 正文 | **EB Garamond** | 长文（伦理页、创作手记、文档正文） |
| 中文无衬线 | Noto Sans SC / 思源黑 | 中文正文、UI、标签 |
| 中文衬线（可选） | 思源宋 / Noto Serif SC | 中文标语、大字引文 |
| 回退栈 | `'Cormorant Garamond','EB Garamond','Liberation Serif',Georgia,serif` | webfont 失败兜底 |

第三方字体（Cormorant / Playfair / EB Garamond / 思源黑·Noto Sans SC）均为 **SIL OFL 许可**，允许自托管；许可声明随 `LICENSE-CONTENT.md` 附出。

### 5.5 色板（双主题）

| Token | 夜（默认） | 纸 |
|---|---|---|
| bg | `#141210` | `#F7F3EC` |
| surface | `#1B1815` | `#FBF8F2` |

### 5.6 调性关键词（四个全要）

**克制的温柔 / 纸与信** × **夜色与一盏灯** 为氛围；**时间的痕迹** × **对话的形态** 为图形母题。

视觉禁区：
- ❌ 具象人像 / 剪影人物（恐怖谷 + 不尊重真实的人）
- ❌ 粉色恋爱风、爱心、"AI 女友"感
- ❌ SaaS 蓝紫渐变、玻璃拟态堆砌
- ❌ 灵异/幽灵感的光影

### 5.7 动效（4 个方向，全部支持 `prefers-reduced-motion` 降级）

| 代号 | 名称 | 描述 | 用途 |
|---|---|---|---|
| M1 | 入场「对望」 | 左右气泡相向滑入 → 镜面轴落下 → 字标渐开字距浮现 | 首屏入场 / 应用启动 |
| M2 | 呼吸「灯」 | 暖光 3.4s 呼吸（scale 1→1.12），幅度克制 | 加载态 / "TA 在打字" |
| M3 | 消息浮现 | 抽象消息条依次浮现（不是真实 UI，是"痕迹"） | 首页 4/5 屏、demo 节奏 |
| M4 | 毕业「消隐」 | 消息痕迹缓缓消隐，浮出一行告别 | 毕业仪式过渡、第 5 屏尾声 |

## 6. 文案策略

- **语言**：中文为主 + 完整英文版（`/en/`）。英文忠实于中文语义，不另起炉灶。
- **语气**：克制短句（主）+ 散文/宣言体（毕业机制、伦理、创作手记）+ 场景叙事（第 2、4 屏）。
- **禁用**：赋能/闭环/抓手式 SaaS 腔、感叹号堆砌、"AI 女友"话术。注：「情感闭环」是产品正典词，不受"闭环"禁用约束。
- **正面使用**：「毕业」「告别」「好好告别」不回避。
- **边界句**：CTA 旁保留一句极小的边界声明（如"仅上传你有权使用的记录"），不展开成板块。

## 7. 信任与伦理规格

**承载**：伦理内容集中在 **`/ethics` 独立页**；首页第 7 屏信任区只放四个要点 + 入口链接。

`/ethics` 必含（五个"不是什么"全上）：

1. **不是替代品**——Mirrai 不是真实关系的替代品
2. **不是挽回工具**——不是教你复合的
3. **同意权前置**——对真实人物建模应事先获得对方同意
4. **专业帮助边界**——不能替代专业心理咨询，附本地求助资源
5. **AI 身份透明**——这是模拟，不是 TA 本人

另含：数据本地 / 记忆锚点防幻觉 / 情感安全层 / 毕业机制"只建议一次"原则 / 开源可审计。

**隐私叙事**双位承载：首页信任区一环 + **`/privacy` 独立页**（`/ethics` 只留链接，不展开）。

**创作手记**全文进 `/about`（媒体与深度读者入口）。

## 8. 功能规格（逐页）

### `/download`
- 三平台安装包（macOS DMG / Windows Setup.exe）+ Docker + 源码
- 系统需求一行（Apple Silicon / macOS 13+；Windows x64；Node 24+ 源码）
- 版本号、发布日期、SHA 校验和（来源：产品仓库 Release 附带的 `SHA256SUMS` 文件——**跨仓依赖**：产品发版流程需生成该文件；**SHA 仅适用于安装包文件**，Docker 卡片展示镜像 digest 或不展示）
- 每版本 Release notes（可读化，不是 commit 列表）
- **自动同步 GitHub Releases**（构建时拉取 API；失败时降级用上次缓存数据，不阻断构建）
- 下载走 `/go/*` 跳转链到真实资产（托管支持 CDN 重定向则真 **302**，否则 meta-refresh），用于零脚本转化统计。**计数口径：仅安装包（macOS/Windows）与 Docker 按钮走 `/go/*`**（Docker 走 `/go/docker` → Docker Hub 镜像页）；源码 / Release notes / 版本历史资产直链 GitHub 不计数；`/en/` 按钮指向同一批 `/go/*` slug，计数合并；跳转链语言无关，不设 `/en/go/*`；`robots.txt` 屏蔽 `/go/*`

### `/blog`
- 版本博客：发版时一篇可读 changelog，兼作 SEO 内容
- MDX in repo（Git-based CMS 编辑）

### `/privacy`
- 隐私说明独立页（页脚"隐私说明"入口指向此页）：**无任何统计脚本、无 Cookie**；下载点击仅通过 `/go/*` 跳转链的**服务器访问日志**计数，不建用户画像；外部可用性拨测不涉及访客数据；主题偏好仅存于你浏览器的 localStorage，不上传

### 产品演示
| 形式 | 分工 | 说明 |
|---|---|---|
| 产品截图 | 用户按摆拍清单在本地产品截 | 暗色 UI、**演示数据**（虚构人名，不得含真实聊天记录）、无隐私泄露 |

### 页脚
GitHub 社区（Discussions/Issues）· 联系邮箱 `ch1rpy@163.com` · 用户群（微信群 + QQ 群，入群方式待定二维码/链接）· 伦理与边界 · 隐私说明（`/privacy`）· ICP 备案号。**英文页脚**：用户群位置改为 GitHub Discussions（海外用户用不了微信/QQ）

**移动端优先**（深夜用手机打开是主场景）；双主题下对比度保持可读（基线要求）。

## 10. 验收标准（按优先级）

1. **移动端优先**——375px 宽下九屏叙事完整、CTA 可点、字体不小于 16px 正文
2. **性能预算**——LCP < 1.5s、Lighthouse 性能终验 ≥95（各里程碑 ≥90）；弱网 4G 模拟
3. **SEO 完整性**——中英 URL 全部可索引、每页独立 title/description、OG 图、sitemap.xml、hreflang
