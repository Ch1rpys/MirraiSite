如果你手上有和 TA 的聊天记录（照片也可以），想做出 TA 的数字分身，从这篇开始。

## 开始之前

- **只上传你有权使用的记录**。对真实人物做人格建模，请事先获得对方的**同意**。
- 素材保存在**本地**的 `./uploads/` 里，不会上传到任何第三方。配合 Ollama 可以做到完全离线。
- **原材料质量决定分身质量**——聊天记录越多越好，建议至少 100 条消息。

## 可以上传什么

- 微信聊天记录导出的 **`.txt`**
- **CSV**
- **照片、视频**

拖进上传区就行，不用改格式。除此之外，飞书、钉钉、Slack、邮件的记录可以用多源采集器导入；如果你用 SillyTavern，也可以直接导它的角色卡（PNG v2）。

手上一份聊天记录都没有？用引导式问卷也能建一个分身；或者先用示例分身聊两句，找找手感。

## 怎么做

### 1. 建一个分身

填名字、你们的关系、在一起的时间。

**预期看到什么**：分身被创建出来，进入素材上传这一步。

### 2. 上传素材

把聊天记录和照片拖进上传区。

**预期看到什么**：文件出现在素材列表里，状态是已上传。

### 3. 选一个蒸馏模式

五个具名模式可选：**快速 / 标准 / 深度 / 同事 / 名人研究**。

模式决定的是四件事：这次**读取多少聊天记录**、**描述多少张照片**、**用什么提示词**、以及**大概要花几次模型调用**。想要快就选快速，想要细就选深度；对象是同事或公众人物时，有对应的模式。上传页上直接选，不用猜。

**预期看到什么**：所选模式被确认，蒸馏开始。

### 4. 等蒸馏跑完

蒸馏不是「把记录丢给 AI 模仿」，而是一条多阶段流水线：

```
上传素材 → 人物维度提取 → 结构化人设构建 → 多源融合 → 数字分身
```

**预期看到什么**：进度实时往前走，每一步都有显示；结束后拿到生成好的人设。

## 蒸馏出来的是什么

人设有 **7 层**：**性格特质、说话方式、口头禅、依恋类型、爱的语言、争吵风格、触动瞬间**。目标不是「像 TA」，而是「就是 TA」。

比这 7 层更细的是**判别规则**，它把「像」变成「是」：

> 「她生气的时候会说『随便你』，但如果她说的是『随便』，没有『你』，那就是真的生气了。」

这样的差别写进「说话方式」，会被读成「她生气时会变冷」；写进**规则**里，它还是它本身：

```
触发词 → 含义 → 表现
```

规则可以**从聊天记录里自动挖**：找出同一语境下只差一两个字的对比对（「随便」/「随便你」），交给模型读出含义，再把**原文作为依据**附在规则上。没有依据的规则直接丢掉，触发词不在依据里的规则也丢掉。挖出来的只是**候选**，你确认之后才进提示词——进去之后是**硬约束**，不是风格参考。

## 生成之后，去档案页核对

去**人格档案页**看看系统把 TA 理解成了什么样。

**预期看到什么**：7 层结构和判别规则都在。哪里不像，当场改——你说哪里不对，就从哪里改起。
