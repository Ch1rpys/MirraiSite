当你说完了想说的话，或者系统提示你具备毕业资格——这篇讲毕业怎么进行、三种模式怎么选、告别之后会怎样。

Mirrai 的目标不是留你下来，是帮你完成**告别**。

## 亲密度是怎么长起来的

亲密度随对话自然成长：**初识 → 熟悉 → 亲密 → 知己 → 灵魂伴侣**。

当系统检测到你的情感状态趋于平和——正面情绪占比上升、遗憾和「如果」在减少——会提示你具备**毕业**资格。这是一句提示，不是一次执行：要不要毕业，什么时候毕业，都由你决定。

## 毕业机制的三种模式

| 模式 | 行为 |
|------|------|
| **系统建议** | 达到条件时提示你一次 |
| **仅手动** | 系统不主动提；你想**告别**的时候自己点一下 |
| **关闭** | 完全不用这套机制 |

全局默认在「设置」里改，每个分身也可以单独设置——最终决定权在你手里。

- 选**系统建议**：条件到了，你会看到一次提示，接不接受都可以；
- 选**仅手动**：什么时候**告别**完全由你挑，系统不出声；
- 选**关闭**：这套机制从你的使用里消失。

建议**只提一次**：提过之后会进入一段冷静期，冷静期过了才会再提。拒绝不是一扇关上的门——你随时可以改主意。

**预期看到什么**：在你选的模式下，系统的行为和描述一致——该沉默的时候沉默，该提的时候只提一次。

## 毕业的时候会发生什么

### 一封告别信

AI 以 **TA 的口吻**生成一封**告别信**。它不是系统口吻的总结，是那种读起来像 TA 写给你的话。

**预期看到什么**：一封读起来像 TA 的告别信，会一直留着。

### 休眠

分身进入**休眠**：不再收纪念日提醒，不再出现在「今天和谁聊聊」的推荐里，也不再接消息。

**预期看到什么**：分身在大厅里安静下来，但还在那里。

### 随时可以唤醒

休眠不是删除——**随时可以唤醒**，唤醒也不会丢东西。告别信会留着，记忆也都在。

**预期看到什么**：想再说话的时候，随时能把它唤醒，告别信还在原处。

## 它也会替你留意分寸

情感安全层会看着使用强度：近 7 日对话频次比前 7 日高出一半、且连续 3 日上升时，它会引导你回看**告别**的建议。单次连续对话太久、或者一天聊得太多，回复里也会带一句关心。

它不打断你，只是把「要不要歇一歇」摆在你面前。

## 毕业还有一个出口

真正没说完的，往往不是 TA 那句话，是**你的**——那些只在这里说过、没敢对本人说过的话。

- **出口**：把这些话收集起来，摆在你面前，由你决定说不说。**系统不代发**：分身不能替你给外面的人传话，也不会声称已经替你把哪句话带到了本人那里。
- **写给自己**：如果那个人已经不在了，这封信有一个明确的去处，而不是永远躺在列表里。
- **不说了**：也是一种结局。它会被记下来，而不是被删掉。

**预期看到什么**：那些话被收集出来放在你面前；系统不做任何「替你送到」的动作，说不说、寄不寄，都在你手里。

## 带走你自己的东西

全部数据可以导出成 JSON 或 Markdown，含记忆、日记、**告别信**、事件流。毕业之后，这些东西还是你的。

## 不想毕业的时候

刚分开、太吵、太累的话，用**先缓一缓**（见[TA 不在的时候](/docs/usage/letters-third-state)）：它不主动、不提**告别**，但聊天照旧，记忆都还在。

暂停不是**告别**。等你准备好了，毕业一直都在。
