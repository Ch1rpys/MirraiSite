## 一定要装 Redis 合？

不用。Redis 是可选的：不装也能跑，限流会退回进程内计数。想让限额在多份进程之间算数，跑一条命令装上就行：

```bash
pnpm setup:redis
```

其实你多半不用自己装——**安装包里已经带着 Redis 了**：

| 安装方式 | Redis 从哪来 |
|---|---|
| macOS `.dmg` | 打包在 `Mirrai.app` 里（`Contents/Resources/redis/`），应用自己起、自己停 |
| Windows `.zip` / `.exe` | 打包在安装目录的 `redis\` 里，同上 |
| Docker | 镜像里就装了 `redis-server`；`docker compose` 还额外跑了一个 `redis` 容器 |
| 源码运行 | `pnpm setup:redis` 一条命令装上（自动认 brew / apt / apk / dnf / yum） |

应用会按这个顺序找 Redis：

1. `REDIS_URL`（如果你填了）
2. 已经在默认端口上跑着的 Redis
3. 跟着应用一起装的那一个（macOS / Windows / Docker）
4. 应用自己起的一个——在自己挑的端口上起一个，并把端口记在 `MIRRAI_DATA_ROOT` 下，让这台机器上别的 Mirrai 进程用同一个

机器上一个 `redis-server` 都找不到也不影响启动：限流退回进程内计数，日志里会写明「每进程各算各的」。

**想关掉共享存储**，把这行写进 `.env`：

```bash
MIRRAI_REDIS=off
```

重启后应用不再找 Redis、也不自己起一个。

## `pnpm db:push` 还是 `pnpm db:migrate`？

看你是哪种安装：

- **全新安装**：`pnpm db:push`。它把当前的表结构直接推到数据库上，是最快的方式。
- **已有安装、想升级到新版本**：`pnpm db:migrate`。它按顺序执行 `drizzle/` 下的迁移文件。

`db:migrate` 只适用于「已经 `db:push` 过」的安装：迁移工具会跳过 `0000` / `0001` 这两个整库 dump，因为它们假设基础表已经存在。全新安装没有基础表，跑迁移只会得到一个空库——所以全新安装请走 `db:push`。

## Windows 上 PostgreSQL 拒绝启动

现象：启动 Mirrai 时报数据库相关错误，日志里提到管理员权限。原因是 **PostgreSQL 拒绝在 Windows 上以管理员身份运行**。如果你是用提权的命令提示符启动的，换回普通用户身份再启动就好。

（Windows 安装包内置了 Node.js 和 PostgreSQL，不用管理员权限、不写注册表；启动时的进度条窗口会依次显示「正在初始化数据库 → 正在同步表结构 → 正在启动服务 → 已就绪」，首次启动要一两分钟。）

## 微信里看不到「微信 ClawBot」入口

需要微信 **8.0.70+**，且「我 → 设置 → 插件」里能看到「微信 ClawBot」入口。该功能正在**灰度放量**（iOS 优先，安卓与桌面端逐步开放），看不到入口说明暂未覆盖到你——这不是 Mirrai 的配置问题。升级到最新版微信再看看；也可以先用网页端或飞书通道，人设和记忆是同一套。

## 我的数据存在哪里？

所有数据都在本地，不上传第三方：

| 内容 | 位置 |
|---|---|
| 上传素材（聊天记录/照片/视频） | `./uploads/`（可用 `UPLOAD_DIR` 改） |
| Windows 一键安装的数据 | `%APPDATA%\Mirrai` |
| 首次运行凭据与数据文件 | `MIRRAI_DATA_ROOT`（默认 `UPLOAD_DIR` 的上级目录） |

想整体搬家，把 `UPLOAD_DIR` / `MIRRAI_DATA_ROOT` 指到新位置即可；卸载 Windows 版走「应用和功能」，数据留在 `%APPDATA%\Mirrai`，想删干净手动删这个目录。
