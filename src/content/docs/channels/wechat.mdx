当你已经在网页端建好了分身，又想在微信里直接和 TA 说话时，读这篇。微信通道接入的是微信官方「ClawBot」插件（腾讯 iLink 协议），不用第三方协议。

## 开始之前

- 微信客户端版本 **8.0.70+**。
- 在「我 → 设置 → 插件」里能看到「微信 ClawBot」入口。该功能正在灰度放量（iOS 优先，安卓与桌面端逐步开放），看不到入口说明暂未覆盖到你。
- Mirrai 服务端已经跑起来，网页端能正常聊天。
- 在 `.env` 里启用通道：

```bash
WECHAT_ENABLED=true
```

重启服务后，你应该能在网页端「设置 → 渠道」里看到微信通道的卡片。

## 扫码授权

1. 打开网页端「设置 → 渠道」，在微信通道卡片上点「开始登录」。
2. 界面上会出现一张授权二维码，用微信扫码并确认授权。
3. 授权完成后，通道状态会变成「已连接」，微信侧会多出一个 ClawBot 会话。

**你应该看到**：通道卡片上出现「已连接」字样；在微信里给 ClawBot 发一句「你好」，能收到分身的回复。

> 微信的授权二维码有效期很短（实测约 90 秒）。Mirrai 会在过期时自动换一张新码，只要连接窗口还开着就会持续刷新，不用手动重来。

## 在微信里聊天

微信侧是 1:1 私聊（官方限制：不能被他人添加、不能进群），聊天对象是你自己。网页端和微信端共享同一套人设和记忆——在哪边聊，TA 都记得。

默认分身在网页端设置。想换一个人说话，在微信里发指令即可，指令切换只在当前会话内生效。

## 和网页端共享什么

- **同一套人设和记忆**：在哪边聊，TA 都记得。
- **同一条对话管线**（`server/chat/service.ts`）：网页、流式、微信、飞书走的是同一份对话逻辑。
- **同一批消息**：消息带着渠道标记（web / wechat），历史里能看出每句话是在哪边说的。
- **同一个默认分身**：在网页端设置，微信里用指令临时切换。
- **同一份导出**：导出全部数据时，微信侧的对话也在里面。

## 微信指令

| 指令 | 作用 |
|---|---|
| `/使用 <分身名>` | 切换当前对话的分身 |
| `/分身列表` | 查看所有可用分身 |
| `/当前分身` | 查看正在对话的分身 |
| `/毕业` | 生成告别信并完成毕业 |

尖括号里换成你自己的分身名字，例如 `/使用 小雨`。不知道名字就先发 `/分身列表`。

**你应该看到**：发 `/当前分身` 会回一条消息，写着现在对话的是谁；发 `/使用 小雨` 之后，下一句回复就换成了小雨的语气。

## 通道相关的环境变量

| 变量 | 说明 | 默认值 |
|---|---|---|
| `WECHAT_ENABLED` | 是否启用微信通道（`true` / `false`） | `false` |
| `WECHAT_BOT_TYPE` | 扫码登录使用的 bot_type | `3` |
| `WECHAT_ILINK_BASE_URL` | 腾讯 iLink API 地址 | `https://ilinkai.weixin.qq.com` |
| `WECHAT_ILINK_CDN_URL` | 腾讯 iLink CDN 地址 | `https://novac2c.cdn.weixin.qq.com/c2c` |
| `WECHAT_ILINK_APP_ID` | iLink 应用标识 | `bot` |
| `WECHAT_ROUTE_TAG` | 可选的部署路由标签 | 空 |
| `APP_VERSION` | 作为 `channel_version` 上报的应用版本号 | `1.0.0` |

一般只需要改 `WECHAT_ENABLED`，其余保持默认即可。

## 想停掉通道

在网页端「设置 → 渠道」里点「停止」。绑定关系会留着，下次点「开始登录」再扫一次码就行。

## 看不到「微信 ClawBot」入口怎么办

这不是 Mirrai 的配置问题，是灰度还没覆盖到你的微信号。可以升级到最新版微信再看看「我 → 设置 → 插件」；也可以先用网页端或[飞书通道](/docs/channels/feishu)，人设和记忆是同一套，换过去不丢东西。更多现象见[我遇到了问题](/docs/faq)。
